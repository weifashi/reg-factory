# 信用卡池紧凑表格实施计划

**Goal:** 按用户批准的邮箱池同款紧凑表格＋详情抽屉替代卡片大块列表。
**Architecture:** 仅修改现有受保护页面的 HTML/CSS/JS，复用 RFPoolRuntime、脱敏 DTO、游标分页和现有编辑表单。无数据库或接口变更。
**Tech Stack:** 原生 DOM、CSS、Playwright/unittest。

- [x] 新增失败测试：表格、详情 Escape、分页尺寸/前后页、移动端、过期清空。
- [x] HTML 使用 tbody#card-list、固定表头、25/50/100 分页和 dialog#card-detail；现有编辑表单移入抽屉。
- [x] JS 安全 textContent 渲染紧凑行；待核对标记常显；详情/编辑共用抽屉；关闭清空短信引用。启停置于更多，保留确认、CAS 和 pending 校验。
- [x] 分页保留已访问游标；搜索修改禁用前后页；查询和修改页尺寸重置第一页；读取失败关闭抽屉、禁用旧写操作。
- [x] 执行卡池 UI 和资源管理/邮箱回归；100 行与手机端截图检查；本机预览只读验证。
- [x] 记录验证与限制。不提交、不重启、不执行任何支付或数据库迁移。

验收：行高约 44px，横向溢出仅在表格内；抽屉只展示脱敏信息；余量明确为账号名额；版本/预留/绑定规则不变。
