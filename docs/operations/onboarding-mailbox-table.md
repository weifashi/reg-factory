## 页面 → 操作 → 结果

```text
资源管理 / 邮箱池 / 列表
  筛选条件 → 查询/刷新 → 服务端筛选，回第一页，清空选择
  每页数量 → 25/50/100 → 服务端分页，不全量下载
  表格滚动 → 表头固定 → 手机可在表格内横向滚动
  当前页全选 → 只选择本页 → 不自动选择服务器上所有邮箱
  上/下一页 → 已访问游标 → 保留跨页已选，显示本页与全部已选数
  点击分组 → 展开编辑 → 保存沿用版本校验和原 PATCH
  更多 → 启用/停用新分配 → 保留原确认和“不释放旧任务/占用”规则
  详情 → 右侧抽屉 → 查看完整邮箱、分组、状态、ID、版本和平台记录
  Escape/关闭 → 收起抽屉 → 返回原详情按钮
```

默认 50 条；无后端总数，不伪造总数或总页数。长邮箱和分组在列表省略显示，详情保留完整内容。健康“正常”只是 HEALTHY 的中文展示，不表示获得注册/试用资格；未知及历史未核清提示保留。只读用户不能勾选任务邮箱或修改分组、启停。
