## 页面 → 操作 → 结果

```text
资源管理 / 信用卡池 / 卡片列表
  查询条件 → 查询/刷新 → 服务端筛选并返回第一页
  每页数量 → 25/50/100 → 服务端分页，不全量下载
  上/下一页 → 已访问的游标 → 显示当前页，不伪造总页数
  列表滚动 → 固定表头 → 手机在表格内部横向滚动

  编辑     → 抽屉表单 → 沿用原 PATCH、版本校验及请求键
  更多     → 启用/停用 → 原确认不变，不释放绑定或预留
  关闭/Esc → 关闭抽屉 → 清空短信替换输入，返回触发按钮
```
